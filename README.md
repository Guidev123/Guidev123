# About me 🔍
I'm a Software Engineer specializing in .NET and Azure. I care about systems that hold up under real conditions and decisions that make sense beyond the technical layer.
 
At XP Inc., one of Brazil's largest investment platforms, I work on the customer onboarding product, a high-traffic system that shapes how new users experience the platform from day one. I've been part of the project since its inception, influencing architectural decisions early and carrying them through full delivery cycles. Along the way I built two internal packages that got picked up by engineers across multiple teams: one replacing a third-party paid solution, another introducing patterns that reduced operational overhead across projects.
 
Before  that, at Sorte Online, I participated in the migration from a proprietary authentication system to Keycloak. I was responsible for the technical design, microservice integrations, and a phased implementation that kept legacy systems running throughout the transition. The end result was the complete removal of the old authentication source code and the introduction of SSO, MFA, passwordless authentication, and social login.
 
I'm drawn to work where architecture decisions have long-term consequences and where understanding the business context is part of doing the technical work well.
